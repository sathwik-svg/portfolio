## ☁️ Deployment

The portfolio is deployed as a **Render Static Site**.

### Render Configuration

```text
Service Type: Static Site
Branch: master
Build Command: None
Publish Directory: .
```

The website is built using static HTML, CSS and JavaScript, so no server-side runtime is required.

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/sathwik-svg/portfolio.git
cd portfolio
```

You can serve it locally with Python:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
